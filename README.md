# 龍山國小 3D 校園導覽

臺中市龍井區龍山國民小學的互動式 3D 校園模型（Three.js）。開啟 `index.html` 或直接瀏覽 GitHub Pages 網址即可使用：
滑鼠拖曳旋轉、滾輪縮放、右鍵／雙指平移，點擊建物飛至該處，可切換日照時間與第一人稱漫遊。

## 資料來源與授權
- 地面底圖：內政部國土測繪中心 2024 年正射影像（政府資料開放授權條款）
- 校地與道路輪廓：© OpenStreetMap 貢獻者（ODbL）
- 建物尺寸與配置：依正射影像量測，並依校方確認與現場照片修正
- 3D 細部模型：Blender 產生，匯出為頁內嵌入的網格資料

頁面只依賴 cdn.jsdelivr.net（Three.js）與 Google Fonts，無後端。
